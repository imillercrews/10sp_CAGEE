# 10sp_CAGEE
R code and bash scripts related to all figures and analyses in manuscript on transcriptome evolution in songbird brains across sex.

Supplemental data, R code and bash scripts related to all figures and analyses in manuscript on transcriptome evolution in songbird brains across sex.


- data/ - this folder contains newick files used for different models of CAGEE in the manuscript. Additionally this contains subfolders with simulated datasets and gene list characterization (chromosomal position and ensembl).
- scripts/ - this folder contains all R scripts (.R files) and bash code (.txt file) used to generate all figures and analyses in the manuscript. This also includes lab e-notebook for this project.
